## 🚀 Featured Projects

### 📡 [SuperPinger](https://github.com/CyberUnagiMaki/SuperPinger)

**Android network diagnostics & monitoring toolkit.**

Ping, traceroute, network scanner, DNS lookup, port scanner, WHOIS, live traffic monitoring and background host availability checks — all from an Android device.

SuperPinger also includes network quality monitoring, packet loss and jitter analysis, IPv4/IPv6 diagnostics, HTTPS/TLS checks, traffic statistics and Telegram alerts when monitored hosts go down or recover.

**Tech:** Kotlin · Android

---

### 🖥️ [SuperPinger Desktop](https://github.com/CyberUnagiMaki/SuperPinger-desktop)

**Network monitoring and diagnostics for Windows.**

A desktop companion to SuperPinger with host monitoring, live ping charts, an interactive OpenStreetMap host map, network traffic tracking, Telegram alerts and a configurable desktop widget.

Includes ping, traceroute, DNS, WHOIS, TCP port scanning, LAN scanning, HTTPS checks and connection-quality diagnostics.

**Tech:** Python · PySide6 · SQLite · Windows

---

### 🐱 [SuperMEOW](https://github.com/CyberUnagiMaki/SuperMeow)

**Digital wellbeing with cats.**

A free Android screen-time companion designed to make reducing phone usage a little more fun.

SuperMEOW tracks screen time, provides daily limits and usage statistics, displays cat reminders when it's time to take a break and includes progression mechanics and a Cat Catcher mini-game.

**Platform:** Android

---

### 🎵 [Now Playing Sync for Telegram](https://github.com/CyberUnagiMaki/Now-Playing-Sync-for-TG)

**Show what you're listening to directly in your Telegram profile.**

A lightweight Windows utility that reads currently playing media through Windows SMTC and automatically updates your Telegram bio or emoji status.

Works with Spotify, browsers, VLC, foobar2000 and other applications that expose media information through Windows.

**Tech:** Python · Windows SMTC · Telethon · Telegram MTProto

---

### 🎮 [Unagi67](https://github.com/CyberUnagiMaki/Unagi67)

**Experimental configurable PC gaming input assistant.**

A small utility exploring configurable input automation, including adjustable vertical mouse compensation and automatic tapping.

> Some games prohibit input-assistance software. Always follow the rules of the game or service you're using.
